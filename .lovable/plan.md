# Automatic gallery orbit

## What will change
- Replace pointer-following movement on the three selected photos with an automatic animation.
- Start the smooth left, right, up, and down orbit when hovered.
- Return each photo to its normal position when the pointer leaves.
- Keep the effect disabled for reduced-motion settings and touch-only devices.

## Technical details
- Use a CSS keyframe sequence for a continuous 360-style photo sweep.
- Keep all existing photos, layout, and gallery content unchanged.
